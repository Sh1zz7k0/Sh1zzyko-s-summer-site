<!-- Как я провёл лето -->

Сайт по макету: хроника лета 2026 (два RAV4, обское море, экзамены, боулинг, Дебаркадер, ремонт, Черёмша).

<!-- Стек -->

- HTML + CSS + JS (без фреймворков)
- БЭМ-именование классов
- Светлая / тёмная тема

<!-- Структура -->

```
summer-site/
├── index.html
├── css/styles.css
├── js/main.js

```

<!-- Как открыть -->

Открыть `index.html` в браузере.

<!-- Отступления от макета -->

- Макет был коллажем с стрелками на одном экране. На сайте — та же логика (месяцы → карточки с фото и текстом), но в вертикальной прокручиваемой ленте, чтобы всё читалось на телефоне, но без стрелочек.
- Добавлена кнопка переключения темы (требование задания).
- Шрифт заголовков: Caveat (рукописный, близко к макету).
